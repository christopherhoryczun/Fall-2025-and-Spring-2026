This assignment is designed to do the following:

1. Write a C program to perform the following:
	Asking the user to enter using the keyboard an integer positive number.
	You should implement a function called reverseDigits that takes thatnumber and returns the number with its digits reversed. For example, given the number 7631, the function should return 1367.

2. Write a C program to perform the following:
	Asking the user to enter using the keyboard 2 integer numbers.
	You should define 2 functions (gcdNonRecursive and gcdRecursive):
		The gcdNonRecursive function takes the 2 numbers and calculates the Greatest Common Divisor (GCD) of the 2 numbers non-recursively.
		The gcdRecursive function takes the 2 numbers and calculates the Greatest Common Divisor (GCD) of the 2 numbers recursively.
