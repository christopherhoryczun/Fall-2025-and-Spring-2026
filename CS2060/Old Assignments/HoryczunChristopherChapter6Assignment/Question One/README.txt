Write a C program to perform the following:
	Asking the user to enter using the keyboard the number of elements of the one dimensional array (positive integer number).
	Initializing its elements by random numbers ranging from 1 (included) to 10 (included).
	Calculating the Mean, Median, and Mode.
	The mode Function
		It can handle a tie for the mode value.
		IF there are 2 values with the same frequency, THEN the data is bimodal and both values should be displayed.
		IF there are more than 2 values with the same frequency, THEN the data is multimodal and all the values with the same frequency should be displayed.
	The median Function
		It calculates the average of the 2 middle elements in an array with an even number.
